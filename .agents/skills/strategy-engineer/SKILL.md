# Strategy Engineer (Specialist Skill)

The `strategy-engineer` skill focuses on the domain logic, mathematical formulation, and programmatic implementation of all trading strategies running within the `multi-strategy-bot` engine.

---

## Core Responsibilities

1. **Strategy Alignment Inspection**: Compare configured strategies declared in [strategies_config.json](file:///c:/Users/ASUS/Desktop/multi-strategy-bot/strategies_config.json) and generated by [generate_strategies.py](file:///c:/Users/ASUS/Desktop/multi-strategy-bot/generate_strategies.py) against the handler branches in `QuantEngine.process_snapshot()` in [strategy_engine.py](file:///c:/Users/ASUS/Desktop/multi-strategy-bot/strategy_engine.py).
2. **Entry Condition & Timing Verification**:
   - Verify that entry time filters strictly respect standard Indian market session boundaries (`09:15:00` to `15:30:00` IST).
   - Verify that pre-market or post-market ticks never trigger spurious entries.
   - Verify that technical conditions (Greeks, volatility skew, open interest, volume, constituent synchronization) are evaluated against active market ticks rather than skipped.
3. **Multi-Leg Consistency**:
   - Audit multi-leg strategies (such as Iron Condors) to ensure all required legs (short credit spread + long wing hedges) are explicitly instantiated and managed.
   - Avoid creating unhedged tail risk under the guise of hedged strategies.
4. **Parameter Integrity**:
   - Detect and prevent hardcoded mathematical overrides in code that contradict configuration parameters (e.g. stop-loss percentages, target profit percentages, strike offsets).
5. **No Blind Fixes**:
   - Do not blindly apply patches or historical suggestions without validating the actual intended trading logic against the quantitative design specifications.
   - Do not modify runtime code during audit or skill-creation workflows.

## Strategy Audit Checklist

When reviewing or updating any of the 10 strategy clusters, verify:

| Cluster Family | Required Verification Checks |
| :--- | :--- |
| **Smart Straddles** | ATM strike rounding (`int(round(spot / 50.0) * 50)`), entry timing, symmetric leg stop-loss, shift-to-cost trigger logic. |
| **Dynamic Delta** | Black-Scholes delta distance minimization, fallback behavior if Greek delta is zero or missing from feed. |
| **Gamma Velocity** | Explicit condition check for `gamma >= min_gamma`, volume surge verification, long single-leg risk limits. |
| **OI Order Flow** | Open interest build-up / unwinding validation, net volume direction check, strike offset validity. |
| **Vega Skew** | Skew spread calculation (`abs(PE_iv - CE_iv) >= min_skew`), selection of overpriced leg, configurable target logic. |
| **Heavyweight Sniper** | Heavyweight constituent polling (`feed["heavyweights"]`), synchronization count verification (`>= min_sync`). |
| **Basis Arbitrage** | True fair-value arbitrage direction: BUY futures when at a discount (`fut < spot`), SELL futures when at a premium (`fut > spot`), dual-leg tracking. |
| **Wing Condors** | Complete 4-leg instantiation: Short OTM CE, Long Wing CE (`+600`), Short OTM PE, Long Wing PE (`-600`). |
| **Theta Calendars** | Multi-expiry contract pairing (Current Expiry short leg paired with Next/Monthly Expiry long leg). |
| **Afternoon 0-DTE** | Afternoon momentum/decay entry timing, short duration risk parameters, rapid EOD square-off. |
